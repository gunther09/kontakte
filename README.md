# Kontakte

Du fügst eine E-Mail-Signatur ein, die App liest daraus Name, Telefon, E-Mail, Firma, Position und Land heraus.

## So geht's

1. `pip install -r requirements.txt`
2. Datei `.env` anlegen mit deinem OpenAI-Schlüssel: `OPENAI_API_KEY=sk-...`
3. `python kontakte.py` starten und `http://localhost:5000` im Browser öffnen.
